GIFTs Documentation
====================

**GIFTs** (Generate IWXXM From TAC) is a pure-Python library that transforms Annex 3
Traditional Alphanumeric Code (TAC) aviation weather products into ICAO
Meteorological Information Exchange Model (IWXXM) XML documents.

IWXXM became a mandatory WMO/ICAO standard on 5 November 2020: Meteorological
Offices must disseminate METAR, SPECI, TAF, and Tropical Cyclone, Volcanic Ash,
and Space Weather Advisories in IWXXM XML form. GIFTs decodes the legacy TAC
text products and encodes them as schema-compliant IWXXM XML.
